        What it handles

        The unglamorous details that make a README printable.

        Fetching

        • Ten filename candidates. README.md, readme.md, README.MD and the rest, including .github/.
        • Branch discovery. The default branch is read from the API, with main and master as fallbacks.
        • Graceful degradation. A rate-limited API still lets the raw fetch continue.
        • Every URL form. owner/repo, .git suffixes, and links that point at a file or folder.

        Resolving & rendering

        • Relative paths. Images point at raw content, document links point at the blob view, and traversal is clamped at the repo root.
        • Code stays intact. Fenced blocks and inline spans are never rewritten.
        • GitHub-flavoured Markdown. Tables, task lists, strikethrough and fenced code all render.
        • Sanitised output. Scripts, styles, frames and forms are stripped before anything reaches the page.

        Private by construction

        There is no backend to upload to. Your Markdown is read, rendered and printed on your own device — the only bytes that leave are the public README files you asked for.
