в виде PDF, готового к печати.

Вставьте URL репозитория, и ReadmePDF загрузит README, подставит изображения и бейджи и сверстает всё для бумаги — прямо в вашем браузере.

Начать преобразование Как это работает

Конвертер

Три способа начать: URL репозитория, файл Markdown или клавиатура. Предпросмотр — это и есть документ.

1 · URL репозитория GitHub

Загружает README (пробует main/master и варианты регистра), подставляет относительные изображения и бейджи и показывает результат ниже. Приватные репозитории не поддерживаются.

2 · …или вставьте / загрузите Markdown

3 · Тема печати

Тёмная тема хорошо читается на экране, но плохо печатается — для печати и PDF мы автоматически осветляем её.

4 · Параметры

Предпросмотр в реальном времени

Экспорт использует печать в PDF вашего браузера (100% на стороне клиента). В диалоге печати выберите «Сохранить как PDF».

Книга документации

Укажите репозиторий, выберите файлы Markdown, которые должны быть вместе, и напечатайте единую книгу с разбивкой на страницы: обложка, общее оглавление и все главы в заданном порядке.

1 · Репозиторий

Находит файлы README, .md, .markdown и .mdown, включая папки. В книге может быть не более 30 файлов; только публичные репозитории.

        Предпросмотр книги

        Книга печатается, только когда загружены все выбранные главы. Экспорт использует печать в PDF вашего браузера — в диалоге выберите «Сохранить как PDF».

        Никаких загрузок. Никаких аккаунтов. Единственный сетевой запрос, который делает инструмент, — анонимное чтение публичного README, который вы указали. Всё остальное — отрисовка, очистка, печать — происходит на вашей машине.

        Как это работает

        Три шага, без аккаунта и без серверного рендерера.

        Шаг 01

        Укажите репозиторий

        Полный URL, краткая запись owner/repo или ссылка с дополнительными сегментами пути — все три варианта ведут к одному репозиторию.

        Открыть конвертер
        Шаг 02

        Посмотрите, как он отрисовывается

        Markdown превращается в HTML прямо в браузере, очищается с помощью DOMPurify и получает оглавление, когда документ этого заслуживает.

        Сравнить темы
        Шаг 03

        Напечатайте в PDF

        Нажмите экспорт, выберите «Сохранить как PDF» — и у вас чистый документ с разбивкой на страницы, без водяного знака и без загрузки.

        Что он умеет

        Неброские детали, которые делают README пригодным для печати.

        Загрузка

        • Десять вариантов имени файла. README.md, readme.md, README.MD и остальные, включая .github/.
        • Определение ветки. Ветка по умолчанию читается из API, а main и master используются как запасные варианты.
        • Устойчивость к сбоям. Даже при ограничении запросов API обычная загрузка может продолжиться.
        • Любая форма URL. owner/repo, суффиксы .git и ссылки, указывающие на файл или папку.

        Подстановка путей и отрисовка

        • Относительные пути. Изображения указывают на исходный контент, ссылки в документе — на просмотр blob, а выход за пределы корня репозитория блокируется.
        • Код остаётся нетронутым. Блоки кода и встроенные фрагменты никогда не переписываются.
        • Markdown в духе GitHub. Отрисовываются таблицы, списки задач, зачёркивание и блоки кода.
        • Очищенный вывод. Скрипты, стили, фреймы и формы удаляются до того, как что-либо попадёт на страницу.

        Приватность по умолчанию

        Здесь нет сервера, куда можно что-то загрузить. Ваш Markdown читается, отрисовывается и печатается на вашем устройстве — наружу уходят только публичные файлы README, которые вы запросили.
