        它能处理什么

        那些不起眼、却决定 README 能否打印的细节。

        获取

        • 十种文件名候选。 README.md、readme.md、README.MD 等，包括 .github/ 目录。
        • 分支发现。 默认分支通过 API 读取，并以 main 和 master 作为回退。
        • 优雅降级。 即使 API 触发限流，原始文件获取仍可继续。
        • 支持各种 URL 形式。 owner/repo、.git 后缀，以及指向文件或文件夹的链接。

        解析与渲染

        • 相对路径。 图片指向原始内容，文档链接指向 blob 视图，路径穿越会被限制在仓库根目录内。
        • 代码原样保留。 围栏代码块与行内代码永远不会被改写。
        • GitHub 风格 Markdown。 表格、任务列表、删除线和围栏代码均可正常渲染。
        • 净化输出。 脚本、样式、框架和表单在进入页面之前即被移除。

        天生私密

        没有可上传的后端。你的 Markdown 完全在自己的设备上读取、渲染和打印——唯一离开浏览器的，是你指定的公开 README 文件。
