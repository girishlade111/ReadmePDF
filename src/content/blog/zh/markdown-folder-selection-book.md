在将散落在多个目录中的 Markdown 文档合并编译为一本完整的 PDF 技术图书时，逐一手工勾选数十个文件极为低效。用户不仅需要能够一键开关整个目录，还需要保留对具体章节的精细控制能力。在 [md2pdf](/#converter) 中，专业的三态（Tri-State）文件夹复选框让技术手册的组织与拼装变得直观且高效。

本文将解析目录级复选框的联动逻辑、三种视觉状态的含义，以及如何将跨目录的 Markdown 文档高效编译为排版精良的 PDF 电子书。

## 深入理解目录复选框的三种状态

在树形文件体系中，非选即中的二元选择无法准确表达“文件夹内仅勾选了部分章节”的中间状态。md2pdf 采用了经典的三态选择设计：

1. **选中状态（全选）**：该文件夹及其所有层级的子目录中的 Markdown 文件已全部被标记为导出对象。
2. **半选状态 / 混合状态（部分选中）**：该文件夹名下的文档有一部分被选中，另一部分被排除。
3. **未选中状态（全不选）**：该目录及其子目录下的所有文档均不参与本次导出。

```text
Tri-State Folder Hierarchy:
[-] docs/guides/             (Indeterminate: partially selected)
    [x] getting-started.md   (Selected)
    [ ] advanced-config.md   (Excluded)
[x] docs/api/                (Checked: all files selected)
    [x] endpoints.md         (Selected)
    [x] authentication.md    (Selected)
```

## 智能双向级联联动逻辑

点击文件夹复选框会触发整棵文档树的智能级联计算：

- **向下同步渗透**：点击一个未选中的文件夹，将一键把其名下的所有子文件和深层子目录标记为全选；点击全选或半选文件夹，则会立即清空其下所有文件的选中标记。
- **向上实时汇总**：在底层勾选或取消某个单独的文件时，系统会自动逐级向上重新评估父级目录直至根节点。当同级文件全部被选中时，父文件夹会自动升级为全选状态。
- **清晰直观的视觉反馈**：半选状态下的横杠（-）指示符让您无需展开文件夹，即可对下属文件的局部勾选情况了然于胸。

## 针对不同场景灵活编撰技术文档手册

借助三态文件夹控件，您可以针对特定读者群体快速组装专门的技术文档：

- **模块专属开发手册**：一键选中 `api/` 和 `sdk/` 目录制作对外接口指南，同时排除面向内部运维的 `admin/` 文档。
- **合规审计交付包**：选中规范文件夹后，单独剔除正在起草中的草稿文件，快速输出正规的审计 PDF。
- **新人入职教程**：将根目录下的 `README.md` 与 `tutorials/getting-started/` 目录下的入门指南融合成册。

## PDF 合并编译时的结构与版式保持

将所选文件夹编译为单本 PDF 电子书时，md2pdf 会在生成物中完美延续逻辑层次：

- **层级目录树**：各个文件夹自然呈现为大章节（卷/篇），每个 Markdown 文件对应一个独立小节。
- **全局连续页码**：跨越所有合并的文档生成统一连续的页码编号，方便打印与翻阅。
- **标准分页符隔离**：章节与文件之间自动插入规范的分页符，杜绝内容拥挤，保证出版级阅读体验。

## 导出编撰完成的 PDF 电子书

完成目录勾选与内容确认后，点击生成按钮。选中的所有 Markdown 文件将被飞速渲染并整合成一本排版优美、包含动态目录与连续页码的高清 PDF 图书。
