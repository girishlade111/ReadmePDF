기업용 모노레포나 규모가 큰 문서 저장소는 수백 개의 마크다운 파일이 여러 계층의 디렉터리에 흩어져 있습니다. 필요한 문서를 찾기 위해 폴더를 일일이 열어보는 것은 번거롭고 시간이 많이 걸립니다. [md2pdf](/#converter)에 내장된 실시간 검색 및 경로 필터링 기능을 활용하면 수천 개의 파일 사이에서도 원하는 문서를 단 몇 초 만에 찾아낼 수 있습니다.

이 글에서는 md2pdf의 클라이언트 사이드 검색 원리, 경로 기반 매칭 규칙, 필터링된 문서를 PDF로 신속하게 내보내는 방법을 소개합니다.

## 대규모 문서 계층 구조 탐색의 어려움

현대 소프트웨어 프로젝트는 API 참조서, 튜토리얼, 운영 런북, 아키텍처 제안서를 한 저장소에 모아두는 경향이 있습니다.

- **방대한 파일 개수**: 대형 프로젝트는 300개 이상의 마크다운 문서를 여러 하위 폴더에 보관합니다.
- **깊은 중첩 구조**: 파일이 네다섯 단계 이상 깊숙한 디렉터리에 저장되어 있는 경우가 많습니다.
- **중복된 파일 이름**: 서로 다른 폴더마다 `index.md`나 `overview.md` 같은 이름이 중복되어 전체 경로 없이는 구분이 어렵습니다.

```text
Search Query Example: "auth/jwt"
Matches:
- docs/services/auth/jwt-validation.md
- guides/security/auth/jwt-tokens.md
Excluded:
- docs/services/billing/invoices.md
```

## 브라우저 내부 실시간 검색 원리

md2pdf의 검색 필터는 파일 트리를 불러올 때 생성된 인메모리 인덱스를 바탕으로 전적으로 사용자 브라우저 내부에서 동작합니다.

검색창에 키워드를 입력하면:

1. **즉각적인 결과 반영**: 서버 통신이나 페이지 새로고침 없이 타이핑 즉시 필터링이 수행됩니다.
2. **파일명 및 경로 일치 검사**: 파일 이름뿐만 아니라 상위 디렉터리 경로까지 함께 검사하므로 `api/v2`와 같은 쿼리로 해당 하위 문서를 즉시 찾을 수 있습니다.
3. **트리 자동 확장**: 일치하는 파일이 포함된 폴더는 자동으로 열리고, 일치하지 않는 폴더는 숨겨져 가독성이 극대화됩니다.

## 필터링된 파일의 편리한 일괄 선택

원하는 문서를 검색한 후에는 내보낼 대상을 손쉽게 선택할 수 있습니다:

- **일괄 선택 토글**: 마스터 체크박스를 클릭하여 현재 화면에 필터링된 파일들만 한 번에 선택할 수 있습니다.
- **세부 항목 조정**: 필터링된 목록에서 불필요한 보조 문서는 개별적으로 체크 해제할 수 있습니다.
- **선택 상태 보존**: 검색어를 지우고 전체 트리 뷰로 복귀하더라도 필터링 중에 선택했던 체크 상태가 그대로 유지됩니다.

## 대용량 문서 저장소에서의 빠른 성능

md2pdf는 가벼운 문자열 인덱싱과 최적화된 렌더링 방식을 사용하여 수천 개의 파일이 있는 대형 저장소에서도 매끄러운 반응성을 제공합니다.

검색 시점에는 경로 문자열만 메모리에서 처리하므로 불필요한 리소스 낭비가 없으며, 시스템 자원을 고품질 PDF 조판 작업에 온전히 집중할 수 있습니다.

## 필터링된 문서 모음의 PDF 변환

검색을 통해 필요한 마크다운 파일을 모두 선택했다면 즉시 변환을 실행할 수 있습니다. 선택된 파일들을 하나의 완성도 높은 PDF 책으로 합치거나, 각 파일을 개별 PDF로 묶은 ZIP 압축 파일로 다운로드할 수 있습니다.
