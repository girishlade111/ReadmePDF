대규모 오픈소스 저장소는 문서들을 수십 개의 중첩된 디렉터리에 분산하여 관리하는 경우가 많습니다. 각 마크다운 파일을 수동으로 찾아서 다운로드하고 변환하는 것은 많은 시간을 소모합니다. [md2pdf](/#converter)를 사용하면 브라우저에서 직접 저장소 파일 트리를 탐색하고 필요한 파일만 손쉽게 선택할 수 있습니다.

이 가이드에서는 md2pdf가 저장소 트리를 파싱하는 방식, 다단계 디렉터리 탐색 방법, 고품질 PDF 출력을 위한 준비 과정을 설명합니다.

## GitHub 저장소 트리 파싱 원리

공개 저장소 URL을 입력하면 md2pdf 클라이언트는 GitHub 공식 API를 호출하여 Git 트리 메타데이터를 가져옵니다. 저장소 전체 아카이브를 불필요하게 다운로드하는 대신, 파일 탐색기 렌더링에 필요한 구조 정보만 선별하여 요청합니다.

가져온 파일 목록은 `.md`, `.markdown`, `.mdown`, `.mkd` 등 지원되는 마크다운 확장자를 기준으로 자동 필터링됩니다. 소스 코드나 불필요한 에셋은 제외되므로 깔끔한 문서 목록만을 확인할 수 있습니다.

```bash
# Expected GitHub repository tree representation
docs/
├── architecture/
│   ├── overview.md
│   └── data-flow.md
├── guides/
│   ├── getting-started.md
│   └── deployment.md
└── api-reference.md
```

## 중첩 폴더 및 파일 계층 구조 탐색

규모가 큰 프로젝트는 기술 문서를 영역별로 나누어 관리합니다. md2pdf의 인터페이스는 페이지 이동 없이 서브 디렉터리를 자유롭게 열고 닫을 수 있는 트리 뷰를 제공합니다.

1. **노드 확장 및 축소**: 폴더명을 클릭하여 하위 항목을 토글합니다. 계층 구조가 그대로 유지되어 문맥을 잃지 않습니다.
2. **상대 경로 확인**: 탐색기에 전체 상대 경로가 표시되므로 각 문서가 저장소 내에서 위치한 맥락을 즉시 파악할 수 있습니다.
3. **파일 내용 검증**: 변환을 시작하기 전에 대상 문서의 존재 여부와 파일 상태를 안전하게 검증합니다.

## 여러 디렉터리에 걸친 마크다운 파일 선택

저장소의 모든 문서를 전부 변환할 필요는 없습니다. md2pdf는 세밀한 파일 선택 기능을 제공합니다:

- **개별 선택**: 서로 다른 디렉터리에 있는 특정 문서들만 체크하여 맞춤형 핸드북을 구성합니다.
- **폴더 일괄 토글**: 폴더 체크박스를 클릭하여 해당 디렉터리 내의 모든 하위 문서를 한 번에 선택하거나 해제합니다.
- **디렉터리 교차 병합**: `docs/` 폴더의 상세 가이드와 루트의 `README.md`를 하나의 일관된 PDF 문서로 병합할 수 있습니다.

## 클라이언트 전용 보안 및 API 속도 제한 최적화

md2pdf의 모든 트리 조회와 문서 다운로드는 사용자의 웹 브라우저 내부에서만 실행됩니다. 개인 액세스 토큰이나 저장소 문서 데이터가 외부 서버로 전송되지 않습니다.

인증되지 않은 일반 세션에서 GitHub API는 IP당 시간당 60회의 호출 제한을 둡니다. md2pdf는 재귀 Git 트리 조회를 통해 요청 횟수를 최적화하여 대형 저장소에서도 끊김 없는 탐색을 지원합니다.
