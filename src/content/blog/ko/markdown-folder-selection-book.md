여러 디렉터리에 분산된 문서들을 단일 PDF 전자책으로 묶을 때, 수십 개의 개별 파일을 일일이 수동으로 선택하는 것은 매우 비효율적입니다. 개별 챕터에 대한 세밀한 제어를 유지하면서도 폴더 전체를 클릭 한 번으로 켜고 끌 수 있어야 합니다. [md2pdf](/#converter)의 삼중 상태(Tri-State) 폴더 체크박스는 맞춤형 기술 핸드북 제작을 직관적이고 확실하게 지원합니다.

이 가이드에서는 디렉터리 단위 체크박스의 동작 원리, 세 가지 상태 표시의 의미, 여러 폴더의 마크다운 트리를 체계적인 PDF 책으로 엮어내는 방법을 설명합니다.

## 디렉터리 체크박스의 세 가지 상태 이해

계층형 파일 시스템에서는 단순한 2단계(선택/해제) 방식만으로는 폴더 내 일부 파일만 선택된 중간 상태를 정확하게 나타낼 수 없습니다. md2pdf는 표준 삼중 상태 모델을 적용합니다:

1. **선택 완료 (전체 선택)**: 해당 폴더와 모든 하위 디렉터리에 포함된 마크다운 문서가 전부 내보내기 대상으로 지정된 상태입니다.
2. **중간 상태 (일부 선택)**: 폴더 내부의 문서 중 일부만 선택되고 나머지는 제외된 상태입니다.
3. **선택 해제 (전체 해제)**: 해당 디렉터리와 하위 폴더의 모든 문서가 내보내기 대상에서 제외된 상태입니다.

```text
Tri-State Folder Hierarchy:
[-] docs/guides/             (Indeterminate: partially selected)
    [x] getting-started.md   (Selected)
    [ ] advanced-config.md   (Excluded)
[x] docs/api/                (Checked: all files selected)
    [x] endpoints.md         (Selected)
    [x] authentication.md    (Selected)
```

## 계층형 캐스케이딩 선택 로직

폴더 체크박스를 클릭하면 트리 전체에 걸쳐 유기적인 상태 전파가 일어납니다:

- **하향 전파**: 체크가 해제된 폴더를 클릭하면 하위의 모든 파일과 서브 폴더가 한 번에 선택 상태로 변경됩니다. 반대로 선택 완료 또는 중간 상태인 폴더를 클릭하면 하위 항목들이 즉시 전부 해제됩니다.
- **상향 전파**: 하위 문서를 개별적으로 선택하거나 해제하면 상위 폴더들의 상태가 루트 디렉터리까지 자동으로 재계산됩니다. 같은 폴더 내 모든 파일이 선택되면 상위 폴더는 자동으로 전체 선택 상태로 전환됩니다.
- **직관적인 시각 피드백**: 대시(-) 모양의 중간 상태 인디케이터 덕분에 폴더를 직접 열어보지 않고도 내부에 일부 선택된 문서가 있음을 즉각 인지할 수 있습니다.

## 용도별 맞춤 기술 핸드북 구성

삼중 상태 폴더 컨트롤을 사용하면 상황에 맞춘 문서를 신속하게 조합할 수 있습니다:

- **모듈별 개발자 안내서**: 외부 개발자용 문서를 만들 때 `api/`와 `sdk/` 폴더만 켜고, 사내 운영용인 `admin/` 폴더는 손쉽게 제외할 수 있습니다.
- **감사 및 규정 준수 패키지**: 컴플라이언스 폴더 전체를 선택한 뒤 검토 중인 초안 파일만 체크 해제하여 공식 제출용 문서를 완성합니다.
- **신규 입사자 가이드**: 루트 디렉터리의 `README.md`와 `tutorials/getting-started/` 폴더의 기초 문서들만 골라 하나의 온보딩 북으로 제작합니다.

## PDF 컴파일 시 디렉터리 계층 보존

선택한 폴더들을 한 권의 PDF 책으로 컴파일할 때 md2pdf는 논리적인 구조를 결과물에 그대로 반영합니다:

- **계층화된 목차 구성**: 폴더 구조는 대단원 섹션으로, 개별 마크다운 문서는 세부 챕터로 목차에 자동 배치됩니다.
- **연속된 페이지 번호 부여**: 포함된 모든 문서에 걸쳐 끊김 없는 단일 일련 페이지 번호가 매겨집니다.
- **깔끔한 장 구분**: 문서와 문서 사이에 적절한 페이지 나눔이 적용되어 출판물 수준의 가독성을 제공합니다.

## 편집한 책의 PDF 내보내기

폴더 선택과 검토를 마쳤다면 변환 버튼을 눌러 PDF 생성을 시작합니다. 선별된 마크다운 문서들이 선명한 글꼴과 클릭 가능한 목차를 갖춘 프로페셔널한 PDF 전자책으로 완성됩니다.
