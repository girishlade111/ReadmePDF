여러 개의 마크다운 문서를 단일 PDF 기술 서적으로 엮을 때, 파일명의 단순 알파벳순 정렬이 최적의 독서 흐름과 일치하는 경우는 드뭅니다. 시작 안내서는 세부 기술 사양보다 앞서야 하며, 환경 설정 가이드는 장애 해결 문서보다 먼저 등장해야 합니다. [md2pdf](/#converter)의 챕터 순서 제어 기능을 활용하면 선택한 문서들의 배치를 손쉽게 재구성할 수 있습니다.

이 가이드에서는 md2pdf에서 챕터 순서를 변경하는 원리, 문서 계층 구조 관리, 출판 품질의 완성도 높은 PDF 책을 엮는 방법을 설명합니다.

## 기술 문서 합본에서 문서 정렬 순서가 중요한 이유

저장소 내부의 파일명은 독자의 이해 흐름보다는 개발자의 명명 규칙을 따르는 경우가 많습니다.

- **비선형적 파일명**: `getting-started.md`와 `architecture.md` 같은 파일은 기본 알파벳순으로 정렬하면 논리적 흐름이 왜곡됩니다.
- **내러티브 완성도**: 효과적인 기술 온보딩을 위해서는 소개, 사전 요구사항, 설치, 핵심 원리, 참조 규격의 순차적 구성이 필수적입니다.
- **목차 일치성**: PDF 내부에 생성되는 대화형 목차는 화면에서 지정한 챕터 순서를 그대로 반영합니다.

```text
Optimized Chapter Order Example:
01. README.md              -> Title & Introduction
02. docs/install.md        -> Prerequisites & Setup
03. docs/quickstart.md     -> First Hands-on Tutorial
04. docs/architecture.md   -> Internal Architecture
05. docs/api-reference.md  -> Complete API Specifications
```

## md2pdf의 직관적인 순서 변경 인터페이스

md2pdf는 PDF를 컴파일하기 전 문서 순서를 매끄럽게 조정할 수 있는 편리한 컨트롤을 제공합니다:

1. **위/아래 이동 버튼**: 클릭 한 번으로 선택한 챕터를 대기열의 위나 아래로 즉시 이동시킵니다.
2. **작업 대기열 시각화**: 문서들이 합쳐질 정확한 순서가 목록 형태로 명확하게 표시됩니다.
3. **초기화 및 자동 정렬**: 필요 시 저장소 기본 순서로 되돌리거나 알파벳순으로 빠르게 정렬할 수 있습니다.

## 챕터 간 문서 계층 구조 표준화

여러 마크다운 파일을 하나로 묶을 때 md2pdf는 제목 레벨을 균형 있게 조정하여 일관된 문서 계층을 만듭니다:

- **챕터 제목 배정**: 각 파일의 최상위 제목이 통합 목차의 독립된 장 제목으로 지정됩니다.
- **소단락 유지**: 파일 내부의 H2, H3 제목은 해당 챕터의 하위 절로 구성되어 PDF 북마크에 계층별로 등록됩니다.
- **자연스러운 장 넘김**: 각 장 사이에 페이지 나눔이 자동으로 적용되어 깔끔하고 가독성 높은 레이아웃을 형성합니다.

## 챕터 간 상호 참조 링크 보존

다중 파일 저장소에서는 `[설정 안내](config.md)`와 같이 상대 경로로 다른 문서를 참조하는 경우가 흔합니다.

md2pdf는 컴파일 과정에서 이러한 상대 경로를 추적하여 PDF 내부 목적지 링크로 변환합니다. 독자는 1장을 읽다가 링크를 클릭하여 4장의 해당 절로 곧바로 이동할 수 있습니다.

## 순서가 지정된 PDF 전자책 컴파일

원하는 순서대로 챕터 배치가 완료되었다면 컴파일 버튼을 누릅니다. md2pdf가 브라우저 메모리 안에서 문서들을 순서대로 결합하고, 균일한 조판과 일련 페이지 번호를 부여하여 완성도 높은 PDF 책을 완성합니다.
