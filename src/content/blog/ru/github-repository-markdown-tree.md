Крупные проекты с открытым исходным кодом часто распределяют документацию по множеству вложенных каталогов. Ручной поиск, загрузка и конвертация каждого файла Markdown в читаемый PDF отнимает много времени. С помощью [md2pdf](/#converter) вы можете анализировать дерево репозитория прямо в браузере и выбирать нужные разделы.

В этом руководстве рассказывается, как md2pdf обрабатывает деревья репозиториев, перемещается по многоуровневым каталогам и готовит документацию к качественному экспорту в PDF.

## Как работает парсинг дерева репозитория GitHub

Когда вы вводите адрес публичного репозитория в md2pdf, клиент отправляет запрос к открытому API GitHub для получения структуры Git-дерева. Вместо скачивания всего тяжелого архива репозитория md2pdf загружает только метаданные, необходимые для построения дерева файлов.

Все обнаруженные элементы проверяются на соответствие форматам Markdown: `.md`, `.markdown`, `.mdown` и `.mkd`. Исходный код и служебные файлы отсекаются, предоставляя удобный и лаконичный список технической документации.

```bash
# Expected GitHub repository tree representation
docs/
├── architecture/
│   ├── overview.md
│   └── data-flow.md
├── guides/
│   ├── getting-started.md
│   └── deployment.md
└── api-reference.md
```

## Навигация по вложенным папкам и иерархиям

Сложные программные пакеты группируют инструкции по тематическим разделам. Интерфейс md2pdf предлагает интерактивное раскрывающееся дерево, в котором можно исследовать подкаталоги без перезагрузки страницы.

1. **Развертывание и сворачивание**: Нажимайте на папки, чтобы отобразить или скрыть содержимое с сохранением структуры.
2. **Относительные пути**: В проводнике отображаются полные пути, поясняющие место каждого документа в архитектуре проекта.
3. **Проверка содержимого**: Убедитесь в наличии необходимых файлов перед началом конвертации.

## Выбор файлов Markdown в разных каталогах

Вам не обязательно конвертировать все документы репозитория подряд. md2pdf предоставляет гибкие инструменты выбора:

- **Точечный выбор**: Отмечайте нужные файлы в разных каталогах для формирования индивидуального руководства.
- **Групповые переключатели**: Нажатие на флажок папки мгновенно включает или исключает все вложенные файлы Markdown.
- **Объединение разделов**: Собирайте статьи из `docs/`, примеры из `tutorials/` и главный `README.md` в единый документ.

## Безопасность на стороне клиента и лимиты API

Все запросы к структуре репозитория и чтение файлов выполняются локально в браузере пользователя. Персональные данные и тексты документов никогда не передаются на сторонние промежуточные серверы.

Для неавторизованных пользователей GitHub устанавливает лимит в 60 запросов в час на один IP. md2pdf использует рекурсивные запросы к дереву Git, экономя лимиты и обеспечивая быструю работу с масштабными проектами.

## Преобразование выбранного дерева в PDF

После выбора целевых файлов Markdown нажмите кнопку компиляции. Вы можете экспортировать каждую статью как отдельный PDF внутри ZIP-архива или объединить все выбранные главы в единую PDF-книгу с оглавлением и сквозной нумерацией.
