В корпоративных репозиториях или обширных порталах документации могут содержаться сотни файлов Markdown, разбросанных по вложенным папкам. Раскрывать каждый каталог вручную утомительно и неэффективно. В [md2pdf](/#converter) встроен быстрый поиск и фильтрация по путям, что позволяет изолировать нужные документы за доли секунды.

В этой статье подробно рассматривается работа клиентского поиска md2pdf, сопоставление путей и быстрый экспорт выбранных статей в PDF.

## Трудности навигации по масштабной документации

Современные программные проекты объединяют спецификации API, руководства пользователя, инструкции по развертыванию и архитектурные схемы в одном репозитории.

- **Большое число файлов**: Крупные системы содержат более 300 документов Markdown в десятках подкаталогов.
- **Глубокая вложенность**: Статьи часто находятся на глубине четырех-пяти уровней.
- **Одинаковые имена**: В разных каталогах часто встречаются файлы с названиями `index.md` или `overview.md`, которые сложно различить без полного контекста пути.

```text
Search Query Example: "auth/jwt"
Matches:
- docs/services/auth/jwt-validation.md
- guides/security/auth/jwt-tokens.md
Excluded:
- docs/services/billing/invoices.md
```

## Механика поиска в браузере в реальном времени

Строка поиска md2pdf работает целиком в памяти браузера, используя оптимизированный строковый индекс, создаваемый при загрузке структуры проекта.

При вводе текста в поисковую строку:

1. **Мгновенный результат**: Фильтрация применяется по мере ввода без отправки сетевых запросов и перезагрузки интерфейса.
2. **Поиск по имени и пути**: Запрос сопоставляется как с именем файла, так и с названиями папок, поэтому запрос `api/v2` выделит все вложенные материалы.
3. **Автоматическое раскрытие**: Найденные папки раскрываются, а нерелевантные скрываются, формируя понятный список документов.

## Выбор найденных документов в один клик

После того как нужные файлы найдены, их легко добавить в список на экспорт:

- **Групповой выбор**: Используйте главный переключатель для отметки всех отфильтрованных файлов, не затрагивая скрытые документы.
- **Индивидуальная настройка**: Быстро снимите отметки с ненужных заметок прямо в результатах поиска.
- **Сохранение отметок**: Очистка поисковой строки возвращает полное дерево файлов, сохраняя ранее проставленные флажки.

## Высокая производительность при больших объемах

Благодаря компактному строковому индексированию поиск md2pdf сохраняет высокую отзывчивость даже в проектах, содержащих тысячи страниц.

В процессе поиска память расходуется экономно, оставляя ресурсы браузера для точной типографической верстки финального PDF.

## Экспорт отфильтрованных документов в PDF

Когда нужные файлы найдены и отмечены, нажмите кнопку компиляции. Вы можете экспортировать объединенную книгу PDF с содержанием и номерами страниц или получить ZIP-архив с отдельными файлами PDF.
