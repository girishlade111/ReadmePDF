При объединении документации из нескольких каталогов в единую PDF-книгу ручной выбор десятков отдельных файлов отнимает много сил. Пользователю необходима возможность переключать целые папки одним щелчком мыши, сохраняя точечный контроль над отдельными главами. В [md2pdf](/#converter) трехпозиционные флажки делают компоновку технических руководств интуитивной и надежной.

В этом руководстве объясняется принцип работы чекбоксов каталогов, значение промежуточных состояний и компиляция многоуровневых деревьев Markdown в структурированные книги PDF.

## Три состояния переключателей каталогов

В иерархических структурах файлов двоичная модель «включено/выключено» не способна отразить частичный выбор. md2pdf применяет стандартную трехпозиционную модель:

1. **Выбрано (Все файлы)**: Все файлы Markdown в этой папке и ее подкаталогах отмечены для экспорта.
2. **Неопределенно / Частично (Смешанный выбор)**: Часть файлов в папке выбрана, а часть исключена из экспорта.
3. **Не выбрано (Ничего)**: Ни один файл в каталоге или его подпапках не войдет в итоговый документ.

```text
Tri-State Folder Hierarchy:
[-] docs/guides/             (Indeterminate: partially selected)
    [x] getting-started.md   (Selected)
    [ ] advanced-config.md   (Excluded)
[x] docs/api/                (Checked: all files selected)
    [x] endpoints.md         (Selected)
    [x] authentication.md    (Selected)
```

## Логика каскадного переключения

Нажатие на чекбокс каталога запускает автоматическое каскадное обновление по всему дереву:

- **Распространение вниз**: Отметка пустой папки выбирает все вложенные файлы и подкаталоги. Нажатие на заполненную или частично заполненную папку снимает все отметки.
- **Распространение вверх**: Выбор или отмена выбора отдельного дочернего файла пересчитывает состояние родительских каталогов до самого верха. Если выбраны все файлы в папке, родительский элемент переходит в статус «Выбрано».
- **Наглядная индикация**: Значок тире (-) сразу показывает, что в папке есть выбранные файлы, даже если сама папка свернута.

## Создание специализированных справочников

Элементы управления папками позволяют компоновать технические руководства за считанные секунды:

- **Руководства по модулям**: Выберите папки `api/` и `sdk/` для подготовки внешнего справочника, исключив внутренние инструкции из `admin/`.
- **Документы для аудита**: Отметьте всю папку стандартов, снимите отметки с черновых файлов и получите официальный PDF для проверки.
- **Материалы для адаптации**: Объедините корневой `README.md` со статьями из `tutorials/getting-started/` в единое пособие для новых сотрудников.

## Сохранение иерархии при сборке книги PDF

При объединении выбранных папок в общую PDF-книгу md2pdf сохраняет логическую структуру проекта:

- **Многоуровневое оглавление**: Папки выступают в роли основных разделов, а файлы Markdown превращаются в главы книги.
- **Сквозная нумерация**: В результирующем PDF формируется единая непрерывная последовательность номеров страниц.
- **Разделители страниц**: Между статьями автоматически вставляются разрывы страниц для обеспечения аккуратного типографического вида.

## Экспорт готовой книги в PDF

После завершения выбора нажмите кнопку компиляции. Отобранные документы будут объединены в презентабельную PDF-книгу с четкими шрифтами и кликабельной навигацией по главам.
