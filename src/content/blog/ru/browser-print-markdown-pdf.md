Даже идеально сверстанный в браузере документ Markdown может выглядеть небрежно, если параметры системного диалога печати выставлены неправильно. Случайные ссылки на полях, даты, пропавший фон в блоках кода или срезанные отступы возникают не из-за ошибок в разметке, а из-за стандартных профилей браузера, созданных для вывода обычных интернет-страниц, а не книг.

md2pdf объединяет директивы CSS для печати (`@media print`) с механизмом печати вашего веб-браузера. При нажатии на кнопку печати подключаются специальные стили, скрывающие интерфейс сайта и управляющие разметкой. Однако выбор формата листа, масштаба, полей и фоновых заливок остается под полным контролем пользователя в окне печати.

В этом руководстве детально рассматриваются параметры Chrome, Firefox, Safari и Edge для получения предсказуемого результата. Для предварительного выбора визуального стиля изучите [руководство по темам печати md2pdf](/ru/blog/readme-pdf-print-themes/).

## Why browser print dialogs require careful configuration

По умолчанию браузер считает, что пользователь делает снимок веб-страницы на память, и автоматически впечатывает по краям листа текущую дату, заголовок вкладки и полный адрес ссылки. В технической документации или деловых отчетах эти элементы выглядят непрофессионально.

Кроме того, браузеры отключают заливку фона ради экономии чернил на физических принтерах. В техническом файле отключение фоновой графики приводит к исчезновению затенения в блоках кода, полос в таблицах и рамок предупреждений, что резко снижает читаемость.

Грамотная настройка этих пунктов превращает рядовую распечатку в полноценное издание типографского уровня.

## Essential print settings: Paper size, margins, and scaling

После открытия системного окна печати установите базовые параметры:

- **Принтер назначения**: выберите **Сохранить как PDF** (Save as PDF).
- **Размер бумаги**: укажите **A4** (международный стандарт) или **Letter** (американский формат) в зависимости от требований.
- **Ориентация**: оставьте **Книжную** (Portrait) для стандартных текстов. Переключайтесь на **Альбомную** (Landscape) только при наличии сверхшироких таблиц.
- **Поля**: выберите **По умолчанию** (Default) или **Нет** (None). В стили md2pdf уже заложены расчетные внутренние отступы, поэтому ручной выбор минимальных полей может прижать текст слишком близко к срезу листа.
- **Масштаб**: оставьте **100%** (По умолчанию). Не уменьшайте масштаб ниже 90%, чтобы шрифты оставались разборчивыми.

## Enabling background graphics for theme fidelity

Самый важный пункт в окне настроек печати — **Фоновая графика** (Background graphics):

```text
[x] Background graphics (Chrome, Edge, Opera)
[x] Print Backgrounds (Firefox)
[x] Print backgrounds (Safari)
```

При включении этого флажка:

- Блоки исходного кода сохраняют темный или серый фон и подсветку синтаксиса.
- Таблицы отображают чередующиеся полосы и выделенные шапки колонок.
- Информационные плашки и предупреждения сохраняют цветовые акценты.
- Декоративные разделители выбранной темы оформления выводятся на печать без потерь.

Без этой настройки все блоки кода напечатаются на прозрачном белом фоне, сливаясь с основным текстом.

## Suppressing unwanted browser headers and footers

По умолчанию браузер добавляет собственные штампы:

- Верхний колонтитул: название страницы и текущая дата.
- Нижний колонтитул: адрес веб-страницы и общий счетчик страниц (например, «1/4»).

В диалоговом окне печати снимите флажок **Колонтитулы** (Headers and footers):

```text
[ ] Headers and footers (Uncheck to remove browser URL and date)
```

Это позволит убрать лишние адреса и даты, сохранив чистое оформление md2pdf.

## Page-break control across headings, tables, and code

В md2pdf встроены автоматические правила CSS, защищающие макет от разрывов:

```css
h1, h2, h3 { break-after: avoid; }
pre, table, figure { break-inside: avoid; }
```

- **Защита от висячих заголовков**: заголовок не останется в самом низу листа в одиночестве — он перенесется на следующую страницу вместе с текстом.
- **Целостность кода**: блоки листингов не разрываются посередине, если только код целиком не превышает высоту страницы.
- **Устойчивость таблиц**: строки таблиц защищены от расщепления вдоль границы листа.

## Browser-specific printing quirks and fixes

- **Google Chrome и Microsoft Edge**: обеспечивают наиболее точный векторный вывод в PDF. Обязательно включите «Фоновую графику» и отключите «Колонтитулы».
- **Mozilla Firefox**: может применять чуть более узкие стандартные поля. Если текст касается края, выберите поля «По умолчанию».
- **Apple Safari**: нажмите «Подробнее» в окне печати, чтобы увидеть флажок «Печатать фон».
