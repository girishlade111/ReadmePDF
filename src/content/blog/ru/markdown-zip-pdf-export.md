Объединение всей документации в одну книгу удобно для сквозного чтения, однако во многих сценариях требуются отдельные файлы PDF для каждого руководства, модуля или регламента. Скачивание десятков файлов по одному засоряет папку загрузок и вызывает предупреждения браузера. С помощью [md2pdf](/#converter) вы можете преобразовать несколько файлов Markdown в независимые PDF и скачать их одним аккуратным ZIP-архивом.

В этом руководстве рассказывается о пакетной генерации PDF, упаковке архивов в браузере с помощью JSZip и структурировании файлов при экспорте.

## Когда отдельные PDF предпочтительнее единой книги

Оба формата решают конкретные задачи распространения документации:

- **Модульное распространение**: Отправляйте нужные инструкции коллегам или заказчикам без передачи всего архива проекта.
- **Микродокументация**: Описания отдельных методов API или примечания к релизам удобнее хранить отдельными файлами.
- **Отсутствие блокировок браузера**: Единый архив предотвращает срабатывание систем защиты от множественной загрузки файлов.

```text
Export Modes in md2pdf:
Mode A (Consolidated Book):
- Multi-chapter single PDF (e.g., project-documentation.pdf)
- Unified Table of Contents & continuous page numbering

Mode B (ZIP Archive Bundle):
- project-docs-bundle.zip
  ├── 01-getting-started.pdf
  ├── 02-architecture.pdf
  └── 03-api-reference.pdf
```

## Создание ZIP-архивов в браузере с помощью JSZip

md2pdf использует библиотеку `JSZip` для формирования архивов непосредственно на стороне клиента, без отправки данных на сервер:

1. **Последовательный рендеринг**: Каждый файл Markdown преобразуется в самостоятельный двоичный буфер PDF с помощью `pdf-lib`.
2. **Понятные имена файлов**: Готовые документы получают названия на основе исходных файлов или главных заголовков статей.
3. **Сжатие в памяти**: По мере завершения верстки каждого PDF его байты немедленно добавляются в поток открытого архива.
4. **Однократное скачивание**: После обработки всех файлов готовый ZIP-архив мгновенно отдается на скачивание одним файлом.

## Сохранение структуры папок внутри ZIP

При экспорте документации из многоуровневых репозиториев md2pdf позволяет сохранить исходную иерархию внутри архива:

- **Сохранение путей**: Файл из `docs/api/endpoints.md` превратится в `docs/api/endpoints.pdf` внутри скачанного архива.
- **Единая плоская папка**: При желании все документы можно поместить в одну общую папку с автоматическим разрешением конфликтов имен.

## Эффективное использование памяти в браузере

Пакетная генерация десятков PDF высокого качества требует аккуратной работы с ресурсами системы.

md2pdf выполняет рендеринг последовательно или небольшими группами, своевременно освобождая временные DOM-элементы и буферы изображений. Такой подход обеспечивает быструю работу сборщика мусора и защищает вкладку браузера от сбоев даже при обработке сотен страниц.

## Экспорт архива ZIP в md2pdf

Чтобы сформировать пакет документов, выберите нужные файлы Markdown в списке, переключите режим вывода на «Отдельные PDF (ZIP)» и нажмите кнопку экспорта. Через несколько секунд архив с готовыми документами будет сформирован и сохранен на ваш диск.
