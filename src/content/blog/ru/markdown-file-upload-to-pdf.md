Конвертация локального файла Markdown в PDF не должна требовать отправки конфиденциальных данных на сторонние серверы. Большинство онлайн-конвертеров обрабатывают документы на бэкенде, сохраняя текст во временных или постоянных базах данных.

md2pdf использует стандартный браузерный API `FileReader`. При выборе локального файла `.md` или его перетаскивании в окно браузера содержимое загружается исключительно в оперативную память. Никакие данные не покидают компьютер, что гарантирует приватность спецификаций и отчетов.

В этом руководстве рассмотрены поддерживаемые форматы, лимиты по объему, кодировки и решение типовых проблем. Если вы предпочитаете вставлять текст из буфера обмена, ознакомьтесь с [руководством по редактированию и вставке Markdown](/ru/blog/markdown-editor-paste-pdf/).

## How local file uploads work in md2pdf

Процесс обработки локальных файлов в md2pdf выполняется полностью на стороне клиента. Выбор документа вызывает событие `change`, после чего поток текста считывается локально:

```javascript
const reader = new FileReader();
reader.onload = (e) => {
  const markdownText = e.target.result;
  renderMarkdownToPreview(markdownText);
};
reader.readAsText(file, 'UTF-8');
```

Полученный текст сразу поступает в редактор и передается в окно предварительного просмотра. Поскольку сетевые запросы HTTP POST отсутствуют, конвертер полноценно работает даже без подключения к интернету.

## Supported file types and extension rules

md2pdf поддерживает стандартные текстовые расширения:

- `.md` — общепринятый формат Markdown.
- `.markdown` — явное расширение файлов Markdown.
- `.txt` — текстовые файлы с разметкой Markdown.

Бинарные форматы (например, `.docx`, `.rtf` или готовые `.pdf`) не поддерживаются. Если ваши материалы хранятся в Word или HTML, предварительно переведите их в чистый Markdown.

## Client-side size limits and encoding

Для стабильной работы вкладки браузера в md2pdf заложены понятные ограничения:

- **Максимальный размер файла**: 2 МБ текста в кодировке UTF-8.
- **Кодировка текста**: UTF-8 без сигнатуры BOM.
- **Переводы строк**: автоматическая нормализация CRLF (`\r\n`) и LF (`\n`).

Файл Markdown объемом 2 МБ содержит около 300 000 слов, что с запасом покрывает большинство технических документов. Если ваш файл больше, разделите его на части или используйте [генератор сборных книг Markdown](/ru/blog/multi-file-markdown-book/).

## Step-by-step: Uploading and printing a local Markdown file

Пошаговый порядок создания PDF из локального документа:

1. Откройте главную страницу md2pdf и найдите панель инструментов.
2. Нажмите **Загрузить Markdown** или перетащите файл `.md` прямо в область редактора.
3. Убедитесь, что текст появился в редакторе и корректно отобразился в окне предпросмотра.
4. Выберите подходящую тему оформления: Clean, Business, Academic или Dark.
5. Включите генерацию **Оглавления (TOC)**, если документ содержит три и более заголовка.
6. Нажмите **Печать / Сохранить в PDF** для вызова диалогового окна браузера.
7. Выберите **Сохранить как PDF**, проверьте поля и нажмите кнопку сохранения.

Подробные рекомендации по параметрам печати описаны в статье [Настройка браузерной печати для Markdown в PDF](/ru/blog/browser-print-markdown-pdf/).

## Handling missing relative assets in local files

При локальной загрузке одного файла браузер из соображений безопасности не имеет доступа к относительным путям к изображениям (например, `![Схема](./images/arch.png)`).

Способы решения проблемы с изображениями:

- Разместите графику на надежном сервере HTTPS и укажите прямые абсолютные веб-адреса.
- Встройте изображения в сам Markdown в виде Base64 Data URI.
- Если документация лежит в репозитории, используйте [импорт README из GitHub](/ru/blog/github-readme-to-pdf/).

## Common upload errors and troubleshooting

- **Искажение символов**: если буквы отображаются некорректно, пересохраните исходный файл в текстовом редакторе с кодировкой UTF-8 без BOM.
- **Зависание страницы**: чрезмерно большие встроенные SVG или гигантские таблицы перегружают отрисовку. Оптимизируйте графику или разбейте документ на главы.
- **Файл не открывается**: проверьте расширение (`.md` или `.txt`). Бинарные файлы, переименованные вручную, будут отклонены.
